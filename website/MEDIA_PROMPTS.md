# RecordPlus - App Context for Media

Use this file to give your AI the product context it needs. It describes what RecordPlus does - not file specs or design instructions.

Product name: RecordPlus

---

## What it is

RecordPlus is a local-first mobile document management app. Users capture important records, add structured details, organize by category and month, and export professional reports when needed.

It is NOT accounting software. It is a lightweight tool for document capture, organization, and export.

Positioning: RecordPlus helps you keep every important record organized, searchable, and ready to share.

---

## Who it is for

- Small business owners
- Freelancers and self-employed users
- Admin and operations staff
- Individuals managing personal paperwork

---

## Core workflow

1. Capture - scan or upload documents
2. Add details - name, category, date, optional amount and notes
3. Organize - profiles, categories, monthly views
4. Export - ZIP packages, financial statements, or document registers

## Document management

Each record can include:

- Name
- Category
- Date
- Optional amount and currency
- Notes
- Original file - image or PDF

Users can:

- Edit metadata after saving
- Move records between profiles
- Change category from item actions
- Delete with confirmation

---

## Export and reporting

### Whole document export

- Export as ZIP
- Includes original files with organized folder structure
- Share via the device share sheet

### Financial export

- For records that have an amount
- Outputs a Financial Statement PDF
- Includes statement header, tabular entries - date, name, category, ref, amount - and a grand total row
- Best for summary review of spending or income records

### Document register export

- Works for records with or without amounts
- Outputs a RecordPlus Document Register PDF
- Includes a summary page, document index table, and visual pages per document
- Layout options:
  - Compact Report
  - Detailed Register Report - one document detail page per item
- Best for audit-ready traceability and document review

## Trust and data handling

- Local-first - documents and data stay on the device
- No automatic upload to external servers
- Sharing only when the user exports or uses share actions
- Profile-scoped records and views
- No forced cloud dependency in the core flow
- User controls retention - records stay until deleted
